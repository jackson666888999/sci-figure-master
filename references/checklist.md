# QA 检查清单

## 基础检查

- [ ] 图表标题清晰传达核心结论
- [ ] 所有轴标签完整（名称 + 单位）
- [ ] 刻度标签可读，无重叠
- [ ] 图例位置合理，不遮挡数据
- [ ] 颜色对比度足够（至少 4.5:1）
- [ ] 无多余网格线或边框
- [ ] 字体大小适中（打印后仍可读）

## 数据完整性

- [ ] 数据点完整，无遗漏
- [ ] 误差线正确标注（SD/SEM/CI）
- [ ] 样本量 n 已标注
- [ ] 统计检验结果已报告
- [ ] 数据范围合理，无异常值未解释

## 期刊合规

- [ ] 图片尺寸符合期刊要求
- [ ] 导出格式正确（PDF/TIFF）
- [ ] 分辨率足够（≥300dpi 用于光栅图）
- [ ] 字体已嵌入
- [ ] 图例字数符合要求

## 美学检查

- [ ] 配色一致（同一图表内）
- [ ] 无彩虹 colormap
- [ ] 无 3D 效果（除非必要）
- [ ] 无装饰性元素
- [ ] 留白合理

## 多面板检查

- [ ] 面板标签（a, b, c...）清晰
- [ ] 面板顺序符合逻辑
- [ ] 面板间风格一致
- [ ] 共享坐标轴正确标注
- [ ] 整体布局平衡

## 打印检查

- [ ] 打印预览无问题
- [ ] 黑白打印仍可辨认
- [ ] 小字体打印后仍可阅读
- [ ] 颜色在黑白模式下有区分度

## 常见问题

| 问题 | 解决方案 |
|------|---------|
| 字体缺失 | 使用系统字体或嵌入字体 |
| 图片模糊 | 使用矢量格式或提高 dpi |
| 颜色失真 | 检查色彩模式 |
| 标签重叠 | 调整字体大小或旋转标签 |
| 图例遮挡 | 移到图表外部 |
| 数据不可见 | 检查颜色对比度 |
